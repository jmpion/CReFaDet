# Changelog

All notable changes to CReFaDet are documented here.

## [1.0.0] — 2026-09-15

- Prepared the dataset for its first versioned paper-release package.
- Standardized the dataset name and repository URLs in the citation metadata.
- Added a complete data dictionary, annotation scopes, missing-value semantics, and supported research tasks.
- Documented the duration-label grammar and the versioned conversion policy for derived values in days.
- Clarified immediate (`0D`), missing-duration, multiple-device, and failure-free usage-time annotation rules.
- Made the license badge, citation metadata, and license notice consistently identify CC BY-NC-SA 4.0.
- Added the complete ordered creator list with ORCIDs and documented the subsequent SSRN preprint that used the dataset.
- Removed a private local path from the workbook metadata and added a SHA-256 checksum.
- Published the release workbook as `CReFaDet-release-v1.xlsx` with the two documented data sheets.
- Validated identifiers, labels, dates, component links, duration syntax, formulas, and workbook rendering.

The values and formulas in the two released data sheets are unchanged from the source workbook.
